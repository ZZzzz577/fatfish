# fatfish

群聊里的 AI 鱼「大肥鱼」：QQ 官方机器人 + deepagents。

## 现在会什么

- **人设**：有来历、性格、口头禅和边界，像群友聊天，不像客服；被问是不是 AI 会承认。
- **被叫才接话**：@ 它会回；群里有人喊「大肥鱼 / 肥鱼 / 胖鱼 / fatfish」也会主动接；引用了它的话也会回。其他消息只旁听、记进上下文，不插嘴。
- **重启不失忆**：消息落盘到 SQLite（`data/history.sqlite`），重启后自动恢复最近 `HISTORY_LIMIT` 条对话；「重置对话」会连落盘一起清掉。
- **接得住追问**：被叫到之后的 90 秒内，群里没点名的提问也会接着回（@ 别人、引用别人的消息除外），比如先发「大肥鱼」再发「今天心情怎么样」。
- **看得懂引用**：别人引用一条消息再提问时，会把被引用的文字、图片、文件名一起交给模型，不依赖本地记忆里是否还留着那条。
- **知道 @ 了谁**：消息里 @ 了哪些人（不含机器人自己）会单独列给模型，即使正文里的 @ 标签被 SDK 清掉也不影响理解。
- **上下文**：每个群/私聊记住最近 `HISTORY_LIMIT` 条消息，知道谁在说话、刚才聊了什么；被引用的消息会自动带进上下文。
- **图片/表情**：消息里的图片会作为图片输入给模型；图片单独发、下一句才 @ 它问时，最近 5 分钟内那张图也会带上（模型或网关不支持视觉时自动降级为纯文本）；表情、语音、卡片会转成可读占位符。
- **输出**：自动去掉 Markdown，超长回复按句子拆成多条发送（最多 4 条），发送失败有兜底话术。
- **指令**：@ 它说「重置对话」清空当前会话记忆；说「帮助」看用法。
- **稳定性**：同一条消息只回一次，同一会话内串行处理，回复顺序和上下文顺序一致；模型调用有超时。

## 目录

```text
index.ts            入口：事件、去重、串行队列、指令、分段发送
src/persona.ts      人设卡 + 聊天提示词拼接
src/context.ts      进程内短期会话记忆
src/message.ts      raw_message 解析、回复清洗、分段
src/store.ts        聊天记录落盘（SQLite）
src/agent.ts        模型与 deep agent 配置、多模态调用
```

## 配置

复制 `.env.example` 为 `.env` 并填写：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `APP_ID` / `APP_SECRET` | 无 | QQ 开放平台机器人凭证 |
| `OPENAI_API_KEY` | 无 | 模型密钥 |
| `OPENAI_BASE_URL` | 空 | OpenAI 兼容网关地址 |
| `OPENAI_MODEL` | `gpt-4o-mini` | 模型名 |
| `OPENAI_TEMPERATURE` | `0.7` | 越高越活泼 |
| `OPENAI_TIMEOUT_MS` | `60000` | 单次模型调用超时 |
| `HISTORY_LIMIT` | `20` | 每个会话保留的上下文条数 |
| `HISTORY_DB` | `data/history.sqlite` | 聊天记录落盘位置 |
| `HISTORY_KEEP` | `500` | 每个会话最多保留多少条落盘记录 |
| `REPLY_MAX_CHARS` | `600` | 单条回复字数上限 |
| `WAKE_WORDS` | `大肥鱼,肥鱼,胖鱼,肥鱼鱼,fatfish` | 不 @ 也会接话的名字，逗号分隔，留空则只响应 @ |
| `FOLLOW_UP_MS` | `90000` | 被叫到后多久内的提问都当在问它，0 表示关闭 |
| `TIMEZONE` | `Asia/Shanghai` | 提示词里用的时区 |

## 运行

```bash
bun install
bun run index.ts   # 启动机器人
bun test           # 跑单元测试
bun check          # 类型检查
```

## 已知限制

- 落盘只保存机器人自己在线的这段时间收到的消息，离线期间的消息、以及进群之前的历史都拿不到（平台没有拉取群历史消息的接口）。
- QQ 官方群机器人只能收到 @ 它的消息，群聊上下文天然稀疏；频道消息可以收到全量。
- 「喊名字接话」需要机器人能收到非 @ 的群消息（如私域机器人或全量消息权限）；只能收到 @ 消息时，这个触发方式不会生效。
- 图片理解依赖所选模型和网关是否支持视觉输入。
